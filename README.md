Task Management Application

Typescript, React + Vite
Auth0 


Requirements / Features: 

Login with Auth0, includes google sign in option.
Task dashboard page 
Task management -- add, edit, view, delete tasks 
State management with typed hooks 

I went with a dark green forest-y color scheme. 

The goal is to create a basic task management application to showcase utilizing Typescript, auth0, hooks, and state management. 
I went with a css file rather than css.module as this app wasn't excessively long, complicated, or unique enough to require that level of concern separation.


To set up:

npm run dev
click the local link
Once at your local link, use the sign in page to sign in.
You'll be redirected to the task dashboard, where you can create and manage your tasks.
